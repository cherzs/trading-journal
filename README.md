# Trading Journal + Strategy Backtester for Scalpers

A streamlined tool designed specifically for scalp traders to track trades, analyze performance, and backtest strategies.

## Features

- **Trade Logging**: Easily log your trades with relevant details
- **Performance Dashboard**: View statistics like winrate, risk-reward ratio, and equity curve
- **Strategy Tags**: Tag and analyze performance by trading strategy
- **Data Import/Export**: Import and export your trading data

## Getting Started

### Prerequisites

- Python 3.8+

### Installation

1. Clone this repository
2. Install required packages:
   ```
   pip install -r requirements.txt
   ```
3. Run the Streamlit app:
   ```
   streamlit run app.py
   ```

## Project Structure

- `app.py` - Main application entry point
- `data/` - Stores trading data
- `utils/` - Helper functions
- `pages/` - Additional pages for the Streamlit app
